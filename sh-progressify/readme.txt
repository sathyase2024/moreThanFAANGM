This is a mock/starter plugin that renders an admin UI inspired by the Progressify PWA plugin for demonstration and prototyping.

== Installation ==
1. Zip the `sh-progressify` folder.
2. In WordPress Admin → Plugins → Add New → Upload Plugin → choose the zip and install.
3. Activate the plugin.
4. Go to the left menu → Progressify to view the mock admin UI.

== Description ==
This plugin does not generate a service worker or manifest yet. It is intended as a UI scaffold to iterate on requirements before implementing actual PWA features.
